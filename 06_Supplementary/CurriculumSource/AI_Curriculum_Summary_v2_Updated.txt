  Module 16: Prompt Engineering                5 days | 15 hrs   [NEWLY ADDED — Career Roadmap]
  ─────────────────────────────────────────────────────────────────────────────────────────────
    16.1  Why Prompt Engineering Matters
           → Why prompt design is a skill, not guesswork
           → Impact on RAG quality, agent behavior, cost
    16.2  Core Prompting Patterns
           → Zero-shot: just ask, no examples
           → Few-shot: examples before the question
           → Chain of Thought: ask LLM to reason step by step
           → ReAct prompting: connects to agents (Module 14)
    16.3  System Prompt Design
           → Persona, constraints, output format, tone
           → Writing system prompts for SK agents
           → System prompt vs user prompt vs assistant prompt
    16.4  Advanced Patterns
           → Self-consistency: run multiple times, take majority
           → Tree of Thought: explore branches of reasoning
           → Meta-prompting: LLM improves its own prompt
           → Prompt chaining: output of one = input of next
    16.5  Prompt Injection Defense                                [NEWLY ADDED — Career Roadmap]
           → What prompt injection is and why it matters
           → Direct injection: user manipulates system prompt
           → Indirect injection: malicious content in retrieved docs
           → Defense patterns: input validation, output filtering,
             separation of instruction and data, Content Safety
           → JM Family context: protecting RAG pipeline from injection
    16.6  Prompt Optimization for Production
           → Reducing token usage without losing quality
           → Temperature and top-p tuning by use case
           → Structured output (JSON mode) for reliable parsing
           → Evaluating prompt quality (groundedness, relevance)

  Module 17: Azure AI Foundry                  4 days | 12 hrs   [NEWLY ADDED — Career Roadmap]
  ─────────────────────────────────────────────────────────────────────────────────────────────
    17.1  What Is Azure AI Foundry
           → Formerly Azure AI Studio — what changed
           → Unified platform: models, evaluation, deployment, safety
           → Where it fits vs Azure OpenAI vs Azure ML
    17.2  Model Catalog
           → 1,600+ models: GPT-4o, Llama, Mistral, Phi-3, Cohere
           → Serverless API vs managed compute deployment
           → How to choose the right model for cost vs quality
    17.3  Prompt Flow — Visual Orchestration
           → Flow canvas: input → embed → search → prompt → LLM → output
           → Node types: LLM, Python, embedding, search, condition
           → When to use Prompt Flow vs Semantic Kernel
           → Export to Python for customization
           → Deploy as REST endpoint directly
    17.4  Evaluation Flows
           → Built-in metrics: groundedness, relevance, coherence, fluency
           → How to run batch evaluation against ground truth
           → Reading evaluation scores and acting on them
           → Using evaluation to compare RAG configurations
    17.5  Fine-tuning in Azure AI Foundry
           → UI-based fine-tuning (no code required)
           → Connecting to Module 15 fine-tuning concepts
           → Monitoring fine-tuned model quality
    17.6  Content Safety and Responsible AI in Foundry
           → Content Safety filters built into every deployment
           → Groundedness detection for RAG outputs
           → JM Family: how to wire Content Safety into pipeline
