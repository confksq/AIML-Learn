The query (`GraphReaderService.cs:214-217`) is the standard Graph **list-items** endpoint:

```

```

This returns the **current field values** of each list item — the live, cumulative state of the document's metadata. The code does **not** touch version history at all: there's no `/versions` navigation, no `$expand=versions`, no version filter anywhere. ## 1. It errs in the unsafe direction
