## Key Mental Models Learned

| Concept | One Line |
|---|---|
| AI Foundry | Azure Portal for AI workloads |
| Hub | Shared infrastructure + governance |
| Project | Team's AI workspace |
| Connections | Key Vault references for AI services |
| Model Catalog | App Store for AI models |
| Prompt Flow | Visual AI orchestrator (low-code) |
| Semantic Kernel | Code-first AI orchestrator (C#) |
| RAG | Give model your data without retraining |
| Evaluation | AI unit tests — score quality automatically |
| Fine-tuning | Customize model behavior with your examples |
| Content Safety | Guard rails on input and output |
| Model Endpoint | Direct REST call to the AI model |
| Prompt Flow Endpoint | Full pipeline (RAG + safety + scores) as one URL |
| API Key | Password for your endpoint — use Key Vault |
| Managed Identity | Zero-secret auth — gold standard for production |
| LLMOps | DevOps + MLOps practices for LLM apps |
| Blue-Green Deploy | Zero downtime rollout via traffic splitting |
| Tracing | App Insights for AI — every step captured |
